# /lhg-ads:audit —— 投放文档体检

> ⚠️ **方法论声明**：审计脚本只检查"机器可判定"的完整性红线（效果承诺、极限词、UTM 缺失、预算表、指标口径），策略好坏仍需人工判断。

用户输入在 `$ARGUMENTS` 中：`[文档目录] [--fix]`。目录缺省为当前项目根目录。

## 流程（加载 lhg-ads-review 第 5 节人工复核清单配合）

### 1. 跑脚本

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/ads_audit.py --target <目录> --format text
```

记下 blocker / warning / nit 的数量与明细（含文件、行号、规则说明）。

### 2. 分级与修复

- blocker（效果承诺 ADS-EFF-001、极限词 ADS-LAW-001、密钥泄露 ADS-SEC-001）：逐条修，`--fix` 缺省即自动修（删除/改写问题表述）；修不掉的列入"需人工处理"。
- warning（预算表/UTM/口径/人群/优化目标）：修掉或写豁免理由。
- nit（标题超长/缺日期版本）：顺手修。
- **为清零改脚本规则或阈值 → 作弊，不许。**

### 3. 人工复核

按 lhg-ads-review 第 5 节清单执行脚本抓不到的：
- 策略合理性：渠道选择与产品是否匹配、人群定义是否具体
- 素材真实性：信任证据是否可验证、价格承诺是否可兑现
- 数据诚实性：复盘结论是否有数据支撑、有无编造归因

### 4. 输出报告

输出分级自查报告，结论写清"通过 / 不通过"（有 blocker 即不通过）。

## 硬规则

- 有 blocker 就说"通过" → 不许。
- 效果承诺类 blocker 不接受豁免，只能删除或改写。
