# /lhg-ads:review —— 数据复盘

> ⚠️ **方法论声明**：本命令提供的是**复盘框架与解读方法**，结论只描述数据呈现的事实；效果归因受平台算法与市场环境影响，不承诺优化后一定起量。

用户输入在 `$ARGUMENTS` 中：`[数据文本或文件路径]`（用户粘贴的真实投放数据）。

## 流程（加载 lhg-ads-review 全程指导）

### 1. 数据清洗

- 确认时间范围、渠道、指标口径（CTR/CVR/ROAS 的定义与归因窗口）
- 口径缺失 → 先让用户确认口径，不许按默认口径脑补解读

### 2. 逐项解读（lhg-ads-review 第 3 节）

按"漏斗顺序"解读：展示→点击（CTR）→落地页→转化（CVR）→投产（ROAS）：
- 每个指标：数值 → 环比/渠道对比 → 只说数据呈现的事实
- **不许编造归因**：数据解释不了的原因写"需进一步验证"，不许硬编

### 3. 结论与优化动作

输出"结论 → 优化动作 → 验证方式"三列表格：
- 每个优化动作必须可执行、可验证（如"标题 A/B 测试"而非"优化素材"）
- 每个动作写清验证指标与观察周期

### 4. 落盘

存为 `ads-review-YYYYMMDD.md`（含时间范围与指标口径章节），跑审计脚本。

## 硬规则

- 没有数据不许复盘；有数据不许编归因。
- 优化动作不许承诺效果（"预计提升 50%"这类话不许写）。
