# lhg-ads-creative：广告素材方法论

> 目标：让小白也能产出"结构正确"的广告素材——标题有公式、创意有结构、落地页能承接承诺。
> 核心纪律：**证据没有就不写，承诺了就必须在落地页兑现。**

## 1. 何时使用

- 投放策略已定，需要配套素材 → 走全流程
- 已有素材，想检查是否踩红线 → 直接跑第 5 节质检门 + 审计脚本
- 只做落地页 → 跳到第 3.4 节

## 2. 输入与输出

**输入：**

| 输入项 | 说明 |
|---|---|
| 产品卖点 | 3 个以内，越具体越好（"0 糖"好过"健康"） |
| 信任证据 | 销量/评价/资质/检测报告——**有才写，没有不许编** |
| 价格与权益 | 价格、优惠、赠品（将用于一致性核对） |
| 投放渠道 | 信息流 / 搜索 / 短视频（决定标题长度与创意形态） |

**输出：** 素材清单文档 = 标题清单 + 创意结构 + 落地页要点 + 一致性核对表。

## 3. 分步方法论

### 3.1 卖点提炼三问

1. 用户为什么买？（解决什么痛点）
2. 为什么买你的不买别人的？（差异化）
3. 凭什么信你？（证据）

每个卖点压缩成 8 个字以内。卖点超过 3 个 = 没卖点，砍到 3 个。

### 3.2 标题公式（每条 ≤30 字）

四个公式轮着用，每组至少覆盖两种：

- **痛点公式**：「还在为 XX 烦恼？」→ 后半句给方案。示例格式："熬夜脸垮垮？试试这款早安面膜"
- **数字公式**：具体数字前置 → "9.9 元体验装，限量 500 份"
- **人群公式**：点名人群 → "久坐党必看：3 分钟缓解腰酸"
- **反差公式**：打破预期 → "别再喝奶茶了，换这个"

**标题铁律：**

- 核心卖点出现在前 10 个字（信息流 3 秒内决定生死）
- 不许出现效果承诺（稳赚/保证/必赚/承诺 ROI）
- 不许出现极限词（第一/最佳/首选/顶级/国家级）
- 信任证据数字必须真实可验证，不许编"10 万人都在买"

### 3.3 创意四段结构

每条创意按固定结构输出：

1. **钩子**（前 3 秒）：痛点提问 / 反常识 / 数字冲击，目标是让人停下来
2. **卖点**（5-10 秒）：只讲 1 个核心卖点，讲透不贪多
3. **证据**（5 秒）：真实评价截图 / 检测报告 / 使用前后对比（有才放）
4. **行动指令**：明确告诉用户下一步做什么（"点击领取 9.9 元体验装"）

短视频口播按同样结构写脚本，信息流图文按"标题+头图+行动按钮"映射。

### 3.4 落地页三要素与一致性核对

**首屏三要素：**

1. 标题承接广告承诺（广告说 9.9 元，落地页首屏必须看到 9.9 元）
2. 核心卖点可视化（一张图讲清，不靠用户读长文）
3. 行动按钮首屏可见（不许藏在三屏之后）

**一致性核对表**（必须输出，逐条打勾）：

| 广告中的承诺 | 落地页对应位置 | 是否一致 |
|---|---|---|
| 9.9 元体验装 | 首屏价格区 | ☐ |
| 限量 500 份 | 首屏库存提示 | ☐ |
| 赠送运费险 | 下单页权益区 | ☐ |

**核心原则：广告承诺的每一条，都必须在落地页找到对应兑现。** 找不到 → 要么落地页加上，要么广告删掉这条承诺。二选一，没有第三条路。

### 3.5 多渠道适配对照表

| 要素 | 信息流 | 搜索 | 短视频 |
|---|---|---|---|
| 标题长度 | ≤30 字，卖点前置 | 贴合搜索词，≤30 字 | 口播前 3 秒即标题 |
| 首屏/首帧 | 头图即卖点 | 标题即答案 | 前 3 秒钩子 |
| 行动按钮 | 图文下方常驻 | 落地页首屏 | 口播+贴纸双指令 |
| 素材寿命 | 7-14 天需换新 | 相对稳定 | 3-7 天需换新 |

**核心：** 同一卖点，三种讲法。不许一条素材全渠道硬投。

### 3.6 标题自检 10 问

1. ≤30 字吗？2. 卖点在前 10 字吗？3. 有效果承诺吗？4. 有极限词吗？
5. 数字真实吗？6. 换成竞品的名字还成立吗（不成立=有差异化）？
7. 用户 3 秒能看懂吗？8. 行动指令明确吗？9. 落地页能承接吗？
10. 读出来像人话吗？

10 问全过，标题才能进清单。

### 3.7 素材迭代节奏

| 渠道 | 换新周期 | 迭代方式 |
|---|---|---|
| 信息流 | 7-14 天 | 标题 2 版轮换，CTR 跌 20% 即换 |
| 搜索 | 按需 | 搜索词变化时跟进，不频繁动 |
| 短视频 | 3-7 天 | 前 3 秒钩子 3 版轮换 |

**判断素材疲劳的信号：** 同一素材 CTR 连续 3 天下滑、频次（人均展示）超过 5 次。出现任一信号就换，不要等"彻底没量"。

## 4. 反模式（这些做法一定错）

1. **标题党**：标题承诺落地页没有 → 跳出率爆炸，还可能被平台判虚假宣传。
2. **编造证据**："10 万+好评"没有就是没有，写上去是欺诈，不是营销。
3. **一个创意讲 5 个卖点**：用户一个记不住。一次一条。
4. **行动指令模糊**："了解一下"不如"点击领取"。用户不思考，只服从。
5. **落地页首屏放品牌故事**：用户是来兑现广告承诺的，不是来读你创业史的。
6. **效果承诺写进标题**："保证赚钱"一时爽，封号火葬场——这是 blocker 红线。

## 5. 自检与反馈

**质检门（素材清单交付前逐项打勾）：**

- [ ] 卖点 ≤3 个，每个 ≤8 个字
- [ ] 标题每条 ≤30 字，核心卖点在前 10 字
- [ ] 全文无效果承诺语（跑审计脚本 ADS-EFF-001）
- [ ] 全文无极限/禁用词（跑审计脚本 ADS-LAW-001）
- [ ] 信任证据全部可验证，无编造数字
- [ ] 每条价格/权益承诺在一致性核对表中有对应行
- [ ] 落地页首屏三要素齐全

**标准冒烟用例：** 用 `fixtures/ads-bad/campaign.md` 跑审计脚本，应命中 ADS-EFF-001 / ADS-LAW-001 / ADS-LPG-001 / ADS-FMT-001；用 `fixtures/ads-good/campaign.md` 跑，应零 blocker。

**一键提 issue：** 发现 bug 或有改进建议，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-ads/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。
